Dependency rules:

  • Generic by default. Anything that isn't domain logic lives in pkg/ and knows nothing about vehicles, documents or sources. internal/ holds the domain and the policies plugged into those packages, and pkg/ never imports internal/.
  • Each layer knows one thing. Clients know an upstream's HTTP API, not paging or the domain. Adapters know how to page one upstream, not HTTP details. The aggregator knows how to page across sources, not upstream formats; inside it, only cursor.go knows the token's encoding.
  • Resilience lives in the transport, so every caller of a client gets retry and a breaker, configured once in wiring.
  • Each layer owns its errors. Clients return client sentinels, adapters turn them into the port's ErrPermanent, the aggregator returns its own, and the handler maps only domain, service and cursor errors to HTTP. No layer inspects another layer's status codes.
  • Each entry point wires itself. The HTTP API builds its graph in handler/api/dependencies.go; another entry point would have its own, calling the same constructors. main only bootstraps.
  • The aggregator's tests run with fake sources and no network; the service never imports the mock package.

Go conventions used throughout

  • Enums are typed constants, never string literals. A zero value is either meaningful (redact.Keep) or deliberately invalid (Status starts at iota + 1; an empty Phase fails Valid); stringer generates names for logs.
  • Wire values live with their owner, mapped only across a contract boundary. Phase names are defined in aggregator and written as is by its cursor token, in the same package. The public API is a separate contract, so dto maps statuses to its own names and owns the error codes. Upstream parameters live in each client.
  • Request validation happens at the edge, with the framework's binding. Gin binds and validates the query string from struct tags (form, binding); only the VIN, a domain type, is parsed by hand (model.ParseVIN). The service documents its preconditions instead of re-checking them.
  • Errors: sentinels checked with errors.Is, typed errors with errors.As, wrapping with %w; error strings are lower-case and never end in punctuation.
  • Constructors return concrete types and validate once (salesapi.New parses its URL), so bad input fails at startup.
  • No globals: loggers, HTTP clients and config are injected; nothing uses slog.Default or http.DefaultClient.
  • Interfaces belong to the consumer: source.Source sits on the aggregator's side; adapters implement it.
  • No import aliases needed: package names don't clash (salesapi the client, sales the adapter; configload and otelsetup in pkg/, so they never collide with the service's own config and telemetry), and parameter names never shadow a package (rawURL, not url).
  • context.Context comes first in every call that blocks or reaches the network.
  • No test logic in production code: no test-only flags, branches or exported helpers; tests use the existing seams (section 12).

3. Core types

Three model layers. Each boundary maps explicitly, so a change on one side doesn't ripple through the others:

  • Domain (internal/model): Document, Entry, SourceRef, VIN, Source. No JSON tags; nothing outside the service sees them.
  • API (internal/handler/api/dto): the request parameters and response JSON, the public contract, mapped from the domain.
  • Wire (model.go in each client under internal/client/): the upstream's payload exactly as it sends it, exported so any code needing raw data can use it. Adapters map it to the domain in mapping.go.

	URL      string

const idSep = ":"

// DocumentID is how a document is identified outside its source,
// "<source>:<upstream id>", so IDs never collide across sources.
func DocumentID(src Source, upstreamID string) string { return string(src) + idSep + upstreamID }

// UpstreamID strips the source prefix from a DocumentID.
func UpstreamID(src Source, id string) string { return strings.TrimPrefix(id, string(src)+idSep) }

// CanonicalType maps an upstream type name to the canonical snake_case set
// (the PRD's example types); anything unknown is "other". Adapters call it,
// so the known set lives in one place. (Signature only.)
func CanonicalType(upstream string) string

// Checksum normalises an upstream file digest: a 64-character hex SHA-256 is
// kept lower-cased; anything else is dropped (empty), since it could never
// match across systems. (Signature only.)
func Checksum(upstream string) string

type VIN string

const (
	vinLength    = 17
	vinForbidden = "IOQ" // excluded by the VIN standard: they look like 1 and 0
)

var ErrInvalidVIN = errors.New("invalid VIN")

// ParseVIN trims and upper-cases the input, then validates it:
// 17 characters, letters and digits only, never I, O or Q.
// The check digit is deliberately not enforced (PRD A-02).
func ParseVIN(raw string) (VIN, error) {
	s := strings.ToUpper(strings.TrimSpace(raw))
	rs := []rune(s) // count characters, not bytes, so a non-ASCII letter is reported at its real position
	if len(rs) != vinLength {
		return "", fmt.Errorf("%w: must be %d characters, got %d", ErrInvalidVIN, vinLength, len(rs))
	}
	for i, r := range rs {
		switch {
		case strings.ContainsRune(vinForbidden, r):
			return "", fmt.Errorf("%w: %q is not allowed (position %d)", ErrInvalidVIN, r, i+1)
		case (r >= 'A' && r <= 'Z') || (r >= '0' && r <= '9'):
		default:
			return "", fmt.Errorf("%w: invalid character %q (position %d)", ErrInvalidVIN, r, i+1)
		}
	}
	return VIN(s), nil
}

	Name() model.Source
	FetchPage(ctx context.Context, req Request) (Page, error)
}

4. Aggregator (draft)

package aggregator

// Status is how one source's call for this page went. The zero value is not a
// valid status, so a SourceResult that was never filled in can't pass as ok.
// Its wire names live in dto, not here.
//
//go:generate stringer -type=Status -trimprefix=Status
type Status int

const (
	StatusOK Status = iota + 1
	StatusTimeout
	StatusError
	StatusDone        // nothing left; not called
	StatusUnavailable // permanent failure; not called again
)

// The service layer's sentinel errors (errors.go). The handler maps these,
// with model's and dto's, to HTTP.
var (
	ErrSourcesUnavailable = errors.New("no source answered")
	ErrInvalidCursor      = errors.New("invalid cursor")
	ErrCursorOutdated     = errors.New("cursor outdated") // a source was added since it was issued
)

// SourcesUnavailableError carries the per-source statuses behind
// ErrSourcesUnavailable, so the 502 response can name them.
type SourcesUnavailableError struct{ Sources []SourceResult }

func (e *SourcesUnavailableError) Error() string { return ErrSourcesUnavailable.Error() }
func (e *SourcesUnavailableError) Unwrap() error { return ErrSourcesUnavailable }

// Retryable reports whether any source failed transiently, so asking again
// with the same cursor may succeed.
func (e *SourcesUnavailableError) Retryable() bool {
	return slices.ContainsFunc(e.Sources, func(r SourceResult) bool {
		return r.Status == StatusTimeout || r.Status == StatusError
	})
}

// Query is everything that defines the list. New dimensions (an order, a
// filter) are added as fields with a default, and to the cursor's token.
type Query struct {
	VIN model.VIN
}

// request is the one place a Query turns into a source.Request: a new Query
// field is mapped here and nowhere else.
func (q Query) request(after *source.Position, limit int) source.Request {
	return source.Request{VIN: q.VIN, After: after, Limit: limit}
}

// Phase is how far a source has got. Its values are also the names the cursor
// writes, so they are defined once, here. The zero value is not a phase, so a
// missing entry can never pass as PhaseStart.
type Phase string

const (
	PhaseStart       Phase = "start"       // nothing returned yet: read from the beginning
	PhaseAfter       Phase = "after"       // At is the last document returned
	PhaseDone        Phase = "done"        // nothing left
	PhaseUnavailable Phase = "unavailable" // failed permanently; not called again
)

// Valid reports whether p is one of the phases above.
func (p Phase) Valid() bool {
	switch p {
	case PhaseStart, PhaseAfter, PhaseDone, PhaseUnavailable:
		return true
	}
	return false
}

type SourceState struct {
	Phase Phase
	At    *source.Position // set when Phase is PhaseAfter
}

// State is where paging stands: which list, and how far each source has got.
// The aggregator pages on it; cursor.go turns it into the token clients hold.
type State struct {
	Query   Query
	Sources map[model.Source]SourceState
}

type SourceResult struct {
	Source model.Source
	Status Status
	Page   source.Page // empty unless Status is ok
}

type Result struct {
	VIN     model.VIN
	Entries []model.Entry // one page, newest first
	Sources []SourceResult
	NextCursor string // opaque token for the next page; empty on the last page
}

// Observer sees what the aggregator does, for metrics: each source call's
// outcome with how long it took, and each request that joined another
// request's fan-out instead of starting its own. internal/telemetry.Metrics
// implements it, so the aggregator records metrics without importing
// telemetry (it depends on model and source only). Declined in the LLD review,
// kept at implementation for that dependency direction (design decision, 2026-10-17).
type Observer interface {
	SourceCall(ctx context.Context, src model.Source, status Status, took time.Duration)
	Coalesced(ctx context.Context)
}

// nopObserver records nothing.
type nopObserver struct{}

func (nopObserver) SourceCall(context.Context, model.Source, Status, time.Duration) {}
func (nopObserver) Coalesced(context.Context)                                     {}

// Builder assembles an Aggregator one source at a time (builder.go), so wiring
// adds sources in a loop instead of filling a constructor by hand.
type Builder struct {
	cfg      Config
	log      *slog.Logger
	observer Observer
	sources  []source.Source
	timeouts map[model.Source]time.Duration
	err      error
}

func NewBuilder(cfg Config, log *slog.Logger) *Builder {
	return &Builder{cfg: cfg, log: log, observer: nopObserver{}, timeouts: map[model.Source]time.Duration{}}
}

// Observe installs the Observer that sees source calls and coalesced requests.
func (b *Builder) Observe(o Observer) *Builder {
	b.observer = o
	return b
}

// AddSource registers src with its own deadline. A duplicate name or a
// non-positive timeout is reported by Build.
func (b *Builder) AddSource(src source.Source, timeout time.Duration) *Builder {
	_, dup := b.timeouts[src.Name()]
	switch {
	case b.err != nil:
	case dup:
		b.err = fmt.Errorf("source %q added twice", src.Name())
	case timeout <= 0:
		b.err = fmt.Errorf("source %q: timeout must be positive", src.Name())
	default:
		b.sources = append(b.sources, src)
		b.timeouts[src.Name()] = timeout
	}
	return b
}

// Build returns the Aggregator, with sources in name order so responses list
// them the same way every time, whatever order they were added in.
func (b *Builder) Build() (*Aggregator, error) {
	if b.err != nil {
		return nil, b.err
	}
	if len(b.sources) == 0 {
		return nil, errors.New("aggregator: no sources")
	}
	slices.SortFunc(b.sources, func(x, y source.Source) int { return cmp.Compare(x.Name(), y.Name()) })
	return &Aggregator{sources: b.sources, timeouts: b.timeouts, cfg: b.cfg, log: b.log, observer: b.observer}, nil
}

// firstPage is the State of a first page: every source from the beginning. With
// decodeCursor checking that all sources are present, every source always has
// an entry, so a missing one can only mean a source added since.
func (a *Aggregator) firstPage(q Query) State {
	st := State{Query: q, Sources: map[model.Source]SourceState{}}
	for _, src := range a.sources {
		st.Sources[src.Name()] = SourceState{Phase: PhaseStart}
	}
	return st
}

// sourceNames lists the configured sources, for decodeCursor's outdated check.
// (Signature only.)
func (a *Aggregator) sourceNames() []model.Source

// ListRequest is one call to List: the list to page through, the opaque
// cursor from a previous Result (empty for the first page), and the limit.
type ListRequest struct {
	Query  Query
	Cursor string
	Limit  int // 1 to the API's maximum; the handler validates it
}

// List returns one page: from the beginning without a cursor, from where the
// cursor left off with one. It is the aggregator's only entry point, so callers
// pass opaque cursors in and out and never see paging state.
func (a *Aggregator) List(ctx context.Context, req ListRequest) (Result, error) {
	st := a.firstPage(req.Query)
	if req.Cursor != "" {
		var err error
		if st, err = decodeCursor(req.Cursor, req.Query, a.sourceNames()); err != nil {
			return Result{}, err // ErrInvalidCursor or ErrCursorOutdated
		}
	}
	return a.coalesced(ctx, st, req.Limit)
}

// coalesced returns one page for st. Identical concurrent requests (same
// query, positions and limit) share one fan-out.
func (a *Aggregator) coalesced(ctx context.Context, st State, limit int) (Result, error) {
	ch := a.flights.DoChan(st.flightKey(limit), func() (any, error) {
		// Detached from the first caller's cancellation (trace values kept),
		// with its own deadline, so one client hanging up doesn't fail
		// every caller sharing this flight.
		fctx, cancel := context.WithTimeout(context.WithoutCancel(ctx), a.cfg.RequestTimeout)
		defer cancel()
		return a.page(fctx, st, limit), nil
	})
	select {
	case <-ctx.Done():
		return Result{}, ctx.Err()
	case r := <-ch:
		res := r.Val.(Result)
		if nothingAnswered(st, res.Sources) {
			su := &SourcesUnavailableError{Sources: res.Sources}
			if su.Retryable() || st.nothingShown() {
				// A 502 carries the statuses and no cursor (HLD section 5).
				return Result{VIN: res.VIN, Sources: res.Sources}, su
			}
			// Documents were shown and every remaining source failed for good:
			// the list is over. A terminal page, not an error (HLD section 4).
		}
		return res, nil
	}
}

func (a *Aggregator) page(ctx context.Context, st State, limit int) Result {
	results := make([]SourceResult, len(a.sources))
	var wg sync.WaitGroup
	for i, src := range a.sources {
		ss := st.Sources[src.Name()]
		switch ss.Phase {
		case PhaseDone:
			results[i] = SourceResult{Source: src.Name(), Status: StatusDone}
			continue
		case PhaseUnavailable:
			results[i] = SourceResult{Source: src.Name(), Status: StatusUnavailable}
			continue
		}
		req := st.Query.request(ss.At, limit)
		wg.Go(func() { results[i] = a.fetchOne(ctx, src, req) }) // own slot, no lock
	}
	wg.Wait()
	docs, next := cut(st, results, limit)
	res := Result{VIN: st.Query.VIN, Entries: toEntries(docs), Sources: results}
	if next != nil {
		res.NextCursor = encodeCursor(*next)
	}
	return res
}

func (a *Aggregator) fetchOne(ctx context.Context, src source.Source, req source.Request) SourceResult {
	fctx, cancel := context.WithTimeout(ctx, a.timeouts[src.Name()])
	defer cancel()
	page, err := src.FetchPage(fctx, req)
	switch {
	case err == nil:
		return SourceResult{Source: src.Name(), Status: StatusOK, Page: page}
	case errors.Is(err, source.ErrPermanent):
		a.log.ErrorContext(ctx, "source rejected the request", "source", src.Name(), "err", err)
		return SourceResult{Source: src.Name(), Status: StatusUnavailable}
	case errors.Is(err, context.DeadlineExceeded):
		return SourceResult{Source: src.Name(), Status: StatusTimeout}
	default:
		a.log.WarnContext(ctx, "source failed", "source", src.Name(), "err", err)
		return SourceResult{Source: src.Name(), Status: StatusError}
	}
}

// cut interleaves the sources' pages newest first, keeps the first limit
// documents, and moves each source's position to the last document it had on
// the page. Documents fetched but cut off come back next time. A transiently
// failed source keeps its old position, so the next page retries it; a
// permanently failed one is marked unavailable.
func cut(st State, results []SourceResult, limit int) ([]model.Document, *State) {
	var docs []model.Document
	for _, r := range results {
		docs = append(docs, r.Page.Docs...)
	}
	// Stable sort on date, then source, only: within one source the upstream's
	// own order (including its ID tie-break) is kept, because that order is
	// what its position means.
	slices.SortStableFunc(docs, func(x, y model.Document) int {
		if c := y.IssuedAt.Compare(x.IssuedAt); c != 0 {
			return c
		}
		return cmp.Compare(x.Source, y.Source)
	})
	if len(docs) > limit {
		docs = docs[:limit]
	}

	next := State{Query: st.Query, Sources: maps.Clone(st.Sources)}
	returned := map[model.Source]int{}
	for _, d := range docs {
		returned[d.Source]++
		next.Sources[d.Source] = SourceState{Phase: PhaseAfter, At: &source.Position{IssuedAt: d.IssuedAt, ID: d.ID}}
	}
	for _, r := range results {
		switch {
		case r.Status == StatusUnavailable:
			next.Sources[r.Source] = SourceState{Phase: PhaseUnavailable}
		case r.Status != StatusOK:
			// transient failure, or already done: position unchanged
		case !r.Page.HasMore && returned[r.Source] == len(r.Page.Docs):
			next.Sources[r.Source] = SourceState{Phase: PhaseDone}
		case returned[r.Source] == 0 && r.Page.SkipTo != nil:
			next.Sources[r.Source] = SourceState{Phase: PhaseAfter, At: r.Page.SkipTo} // step past a fully malformed page
		}
	}
	for _, ss := range next.Sources {
		if ss.Phase != PhaseDone && ss.Phase != PhaseUnavailable {
			return docs, &next
		}
	}
	return docs, nil // every source finished
}

// flightKey identifies identical requests. %+v includes every Query field, so
// new dimensions join the key without code changes.
func (s State) flightKey(limit int) string {
	var b strings.Builder
	fmt.Fprintf(&b, "%+v|%d", s.Query, limit)
	for _, name := range slices.Sorted(maps.Keys(s.Sources)) {
		ss := s.Sources[name]
		fmt.Fprintf(&b, "|%s:%s", name, ss.Phase)
		if ss.At != nil {
			fmt.Fprintf(&b, ":%s:%s", ss.At.IssuedAt.Format(time.RFC3339Nano), ss.At.ID)
		}
	}
	return b.String()
}

// toEntries maps each document to one entry. Today every entry has one source;
// the planned checksum index (HLD section 14) would add the other systems
// holding the same file.
func toEntries(docs []model.Document) []model.Entry {
	entries := make([]model.Entry, len(docs))
	for i, d := range docs {
		entries[i] = model.Entry{
			Type: d.Type, Title: d.Title, Summary: d.Summary, IssuedAt: d.IssuedAt,
			Sources: []model.SourceRef{{Source: d.Source, ID: d.ID, URL: d.URL}},
		}
	}
	return entries
}

// nothingAnswered is true when no source answered and at least one failed,
// transiently or permanently (PRD A-05: if every system fails, show an error).
// A source answering with nothing (404, an empty page) still counts as an answer.
// A source already done or unavailable when the page started was not asked, so
// it neither answered nor failed: a cursor in which every source has finished
// gives an empty last page, not an error.
func nothingAnswered(st State, results []SourceResult) bool {
	failed := false
	for _, r := range results {
		if prev := st.Sources[r.Source].Phase; prev == PhaseDone || prev == PhaseUnavailable {
			continue // not asked this page
		}
		switch r.Status {
		case StatusOK:
			return false
		case StatusTimeout, StatusError, StatusUnavailable:
			failed = true
		}
	}
	return failed
}

Design notes

  • One entry point: List. The handler passes the query, the raw cursor and the limit, and gets an opaque NextCursor back. First page or resume, decoding and encoding all happen inside; firstPage and the cursor functions are unexported, so no caller can combine them wrongly.
  • Paging never touches the token. It works on State; cursor.go is the only file that knows the token's JSON, so the token format can change without touching paging.
  • Sources take a Request, not positional parameters. A future filter or order is a new field with a zero-value default, mapped once in Query.request; the Source interface, the adapters and the fake sources don't change. An adapter that can't honour a field returns ErrUnsupported (permanent), so a filter is never silently dropped.
  • A source's position is the last document returned, not the upstream's next-page token. Each source is asked for limit documents, but only limit in total survive the cut. Passing the upstream's token through would silently skip whatever was fetched but cut off.
  • A position needs both the date and the ID. Each system orders by date and then ID, so "after this document" compares both. An ID alone fails because IDs don't follow dates (backfilled records, text IDs) and can't place a cursor among same-day ties. Carrying the date also keeps the cursor self-contained: it still works if the anchor document is deleted between pages.
  • Never re-sort within a source. The upstream's order, including its ID tie-break, is what its position means. Re-sorting by our ID string would break it: as text, service:10000 sorts before service:9001, while the Service system orders record IDs as numbers. The stable sort compares only date and source.
  • A fully malformed upstream page would stall the cursor. Adapters skip malformed items; if every item on a page was malformed, SkipTo carries the last raw item's position so the cursor moves past it instead of asking for the same page forever.
  • Pages can be short. A failed source contributes nothing, so a page can hold fewer than limit documents. Clients page on next_cursor, not on count.
  • A failed page has no cursor. When nothing answered and a retry may help, or nothing has been shown yet, List returns the per-source statuses and ErrSourcesUnavailable but no NextCursor: the client retries the cursor it already holds (HLD section 5). Only sources asked on this page count as failed; one finished on an earlier page was never called, so a cursor in which every source is already done or unavailable yields an empty last page rather than a 502.
  • All-permanent failure after documents were shown is a terminal page. State.nothingShown is true while every stream is still at start. Once something has been shown, a page where every remaining source fails permanently returns 200 with no documents, those sources unavailable and no cursor, so the client is never left holding a cursor that can only 502 (review finding 6).
  • Panics are contained. Each per-source goroutine and the fan-out itself recover: a panicking source counts as a transient error for this page (retried next page) and is logged with its stack, so one bad adapter can't take the request down. The recovery has to be inside the fan-out because singleflight re-raises a panic in the leader where no middleware can catch it.
  • A stalled source ends. A source that answers ok with an empty page, has_more true and no SkipTo would be asked the same question forever; the aggregator marks it unavailable instead, so the list ends rather than looping.
  • Every source gets the full limit, never a share of it. The newest limit documents may all sit in one source; asking each of N sources for limit / N would push its newer documents onto later pages, behind older ones from other sources. The cost is over-fetch: N × limit fetched to return limit (60 for 20 with three sources), bounded by the max of 100, and the cut-off part is fetched again next page. That's the price of staying stateless.
  • WaitGroup, not errgroup.WithContext. errgroup cancels the shared context on the first error, which would kill the healthy source's call. Each goroutine writes only its own slot, so no lock is needed. wg.Go exists since Go 1.25; the module targets Go 1.27 (go 1.27 in go.mod, golang:1.27 in the Dockerfile).
  • singleflight with a detached context. Otherwise the first caller's context governs the shared fan-out, and if that client disconnects, every caller in the flight fails. Each caller still stops waiting when its own context ends.
  • Context reaches the upstream. httpjson builds every request with http.NewRequestWithContext, so a deadline or cancellation stops the upstream call, not just our wait for it.

5. Resilience (draft)

pkg/resilience is generic and transport-agnostic: Guard[T] protects any call, whether an HTTP request, a gRPC call or a database query. Each transport gets a thin adapter package on top, as with otelhttp and otelgrpc: resiliencehttp.NewTransport today. A gRPC client would get resiliencegrpc, a unary client interceptor built on the same Guard, with its own idea of a failed call (codes.Unavailable, codes.ResourceExhausted); the core doesn't change. Every caller of the Sales or Service client gets retry and a breaker without knowing about them, and adapters and the aggregator contain no resilience code.

Wiring, outside in, one stack per upstream so each has its own breaker: tracing (otelhttp), then the resilience transport, then a pooled http.Transport. With the breaker outside the retry, one logical call counts as one failure, and an open breaker skips retries entirely.

package resilience

// Policy decides what is worth retrying and what counts against the breaker.
type Policy struct {
	MaxRetries int              // extra attempts after the first
	MinBudget  time.Duration    // deadline that must remain before a retry
	MaxJitter  time.Duration    // upper bound of the wait before a retry
	Retryable  func(error) bool // errors worth another attempt
	Ignore     func(error) bool // errors that say nothing about the callee's health
	TripAfter  uint32           // consecutive failures that open the breaker
	Cooldown   time.Duration    // time open before a probe
	OnState    func(name string, from, to gobreaker.State)
}

// Guard puts calls returning T behind a circuit breaker and a bounded retry.
type Guard[T any] struct {
	cb     *gobreaker.CircuitBreaker[T]
	policy Policy
}

func NewGuard[T any](name string, p Policy) *Guard[T] {
	if p.Retryable == nil {
		p.Retryable = func(error) bool { return false } // nothing is retried unless the policy says so
	}
	return &Guard[T]{policy: p, cb: gobreaker.NewCircuitBreaker[T](gobreaker.Settings{
		Name:          name,
		Timeout:       p.Cooldown,
		ReadyToTrip:   func(c gobreaker.Counts) bool { return c.ConsecutiveFailures >= p.TripAfter },
		IsSuccessful:  func(err error) bool { return err == nil || (p.Ignore != nil && p.Ignore(err)) },
		OnStateChange: p.OnState,
	})}
}

// Do runs call through the breaker, retrying inside it.
func (g *Guard[T]) Do(ctx context.Context, call func(context.Context) (T, error)) (T, error) {
	return g.cb.Execute(func() (T, error) { return retry(ctx, g.policy, call) })
}

func retry[T any](ctx context.Context, p Policy, call func(context.Context) (T, error)) (T, error) {
	v, err := call(ctx)
	for i := 0; err != nil && i < p.MaxRetries && p.Retryable(err) && hasBudget(ctx, p.MinBudget); i++ {
		select {
		case <-time.After(time.Duration(rand.Int64N(int64(p.MaxJitter) + 1))):
		case <-ctx.Done():
			var zero T
			return zero, ctx.Err()
		}
		v, err = call(ctx)
	}
	return v, err
}

func hasBudget(ctx context.Context, min time.Duration) bool {
	deadline, ok := ctx.Deadline()
	return !ok || time.Until(deadline) > min
}
package resiliencehttp // a resilience.Guard as an http.RoundTripper

// ErrFailedResponse marks an attempt whose response counted as a failure. It
// never reaches the caller: after the last attempt the response itself is returned.
var ErrFailedResponse = errors.New("failed response")

// NewTransport puts requests through a breaker and a bounded retry. failed
// decides which responses count as failures (e.g. 5xx and 429). Only GET and
// HEAD are retried, so a retry never repeats a change.
func NewTransport(next http.RoundTripper, name string, p resilience.Policy, failed func(*http.Response) bool) http.RoundTripper {
	retryable := p.Retryable
	p.Retryable = func(err error) bool {
		return errors.Is(err, ErrFailedResponse) || (retryable != nil && retryable(err))
	}
	return &transport{next: next, failed: failed, guard: resilience.NewGuard[*http.Response](name, p)}
}

type transport struct {
	next   http.RoundTripper
	failed func(*http.Response) bool
	guard  *resilience.Guard[*http.Response]
}

func (t *transport) RoundTrip(req *http.Request) (*http.Response, error) {
	if req.Method != http.MethodGet && req.Method != http.MethodHead {
		return t.next.RoundTrip(req)
	}
	var last *http.Response // the latest failed response, closed if it is retried
	resp, err := t.guard.Do(req.Context(), func(ctx context.Context) (*http.Response, error) {
		if last != nil {
			last.Body.Close()
			last = nil
		}
		r, err := t.next.RoundTrip(req.Clone(ctx))
		if err == nil && t.failed(r) {
			last = r
			return r, ErrFailedResponse
		}
		return r, err
	})
	if errors.Is(err, ErrFailedResponse) {
		return resp, nil // retries spent: hand the failed response to the caller
	}
	if last != nil {
		last.Body.Close() // gave up while waiting to retry
	}
	return resp, err
}

The upstream policy, set at wiring:

  • Failed responses: 5xx and 429 count as failures. Other 4xx don't, since an upstream rejecting a request says nothing about its health.
  • Retries: MaxRetries: 1, with MinBudget and MaxJitter from configuration. Retryable adds connection errors to failed responses; context errors and an open breaker are never retried.
  • Ignored errors: context.Canceled, since a client hanging up says nothing about the upstream.
  • Breaker: TripAfter: 5, Cooldown: 30s; OnState feeds the breaker-state metric.

6. Clients, adapters and field mapping

Clients (internal/client/...): one per upstream, built on pkg/httpjson. Each knows its endpoints, query parameters and wire models, and nothing about paging rules or the domain, so other code can call it for raw data.

package httpjson

// StatusError is a non-2xx response.
type StatusError struct{ Code int }

func (e *StatusError) Error() string { return fmt.Sprintf("http status %d", e.Code) }

var (
	ErrTooLarge = errors.New("response body over the size limit")
	ErrDecode   = errors.New("response body doesn't decode")
)

type Client struct {
	HTTP     *http.Client // its transport carries tracing and resilience
	MaxBytes int64
}

// Get fetches rawURL and decodes a JSON body into T. A non-2xx response returns
// *StatusError without decoding; a body over MaxBytes returns ErrTooLarge.
func Get[T any](ctx context.Context, c Client, rawURL string) (T, error) {
	var zero T
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, rawURL, nil)
	if err != nil {
		return zero, err
	}
	resp, err := c.HTTP.Do(req)
	if err != nil {
		return zero, err // transport error, including context and open-breaker errors
	}
	defer resp.Body.Close()
	if resp.StatusCode < http.StatusOK || resp.StatusCode >= http.StatusMultipleChoices {
		_, _ = io.Copy(io.Discard, io.LimitReader(resp.Body, c.MaxBytes)) // lets the connection be reused
		return zero, &StatusError{Code: resp.StatusCode}
	}
	body, err := io.ReadAll(io.LimitReader(resp.Body, c.MaxBytes+1))
	if err != nil {
		return zero, err
	}
	if int64(len(body)) > c.MaxBytes {
		return zero, ErrTooLarge
	}
	var v T
	if err := json.Unmarshal(body, &v); err != nil {
		return zero, fmt.Errorf("%w: %w", ErrDecode, err)
	}
	return v, nil
}

var (
	ErrNotFound    = errors.New("upstream: not found")          // 404
	ErrRejected    = errors.New("upstream: request rejected")   // 400, 401, 403, 422
	ErrUnavailable = errors.New("upstream: unavailable")        // 5xx, 429, connection errors, open breaker
	ErrTooLarge    = errors.New("upstream: response too large") // over the size cap
	ErrMalformed   = errors.New("upstream: malformed response") // body doesn't decode
)

// rejectedStatuses are the responses that say the request itself is wrong.
var rejectedStatuses = []int{
	http.StatusBadRequest, http.StatusUnauthorized, http.StatusForbidden, http.StatusUnprocessableEntity,
}

// FromHTTP wraps an httpjson error in the matching sentinel, keeping the
// original for logs. Context errors pass through unchanged, so deadlines and
// cancellations stay recognisable.
func FromHTTP(err error) error {
	var se *httpjson.StatusError
	switch {
	case err == nil, errors.Is(err, context.Canceled), errors.Is(err, context.DeadlineExceeded):
		return err
	case errors.As(err, &se) && se.Code == http.StatusNotFound:
		return fmt.Errorf("%w: %w", ErrNotFound, err)
	case errors.As(err, &se) && slices.Contains(rejectedStatuses, se.Code):
		return fmt.Errorf("%w: %w", ErrRejected, err)
	case errors.Is(err, httpjson.ErrTooLarge):
		return fmt.Errorf("%w: %w", ErrTooLarge, err)
	case errors.Is(err, httpjson.ErrDecode):
		return fmt.Errorf("%w: %w", ErrMalformed, err)
	default:
		return fmt.Errorf("%w: %w", ErrUnavailable, err)
	}
}

Shared rules

  • Paging (Sales): the adapter sets BeforeDate (YYYY-MM-DD) and BeforeID (the upstream ID, via model.UpstreamID); the client sends them as before=2024-03-02|S-1002.
  • Paging (Service): the adapter sets BeforeTS (epoch seconds) and BeforeID (the upstream ID, via model.UpstreamID); the client sends before_ts and before_id.
  • Order: adapters return documents in the upstream's order and never re-sort them.
  • Errors, layer by layer:
    • the client turns HTTP outcomes into its sentinels (client.FromHTTP): 404 is ErrNotFound; 400, 401, 403, 422 are ErrRejected; over 1 MB is ErrTooLarge; bad JSON is ErrMalformed; 5xx and 429 after the transport's retry, connection errors and an open breaker are ErrUnavailable;
    • the adapter maps those (errmap.FromClient): not found is an empty, final page (done); rejected, too large and malformed are ErrPermanent; unavailable and context errors are transient.
  • Malformed items: an item missing its ID, date or URL is skipped and counted in a metric. If every item on a page is malformed, the adapter sets SkipTo to the last raw item's position.
  • Body limit: httpjson reads at most 1 MB (sources.max_body_bytes). Beyond it the client reports client.ErrTooLarge, which the adapter treats as permanent: the same request would return it again.
  • Lookup key: both upstreams are queried by VIN directly (HLD D-10). A system that needed an ID lookup first would do it inside its own adapter.

7. HTTP layer

  • Router and middleware (Gin), outermost first: request logging (slog, also records the duration metric; outside recovery so it sees the status a panic ends with, and a hang-up as 499) → gin.CustomRecovery (a panic becomes internal_error, logged with its stack) → OpenTelemetry (otelgin) → rememberSpan, a tiny middleware that keeps the span context for the logger (otelgin doesn't share its request with outer middleware) and, when that context is valid and sampled, sets the X-Trace-Id response header to the W3C trace ID (HLD D-14) → CORS (gin-contrib/cors, allow-list from config, answers preflight requests, exposes X-Trace-Id to browser callers) → handler. Health probes are logged at debug and, being untraced, carry no X-Trace-Id.
  • X-Trace-Id: on every traced response, success or error, set before the handler runs so writeError and the 200 path need no header code of their own. 32 lower-case hex characters, the same value as trace_id in the request log and the span in Tempo; random, so no PII. Body shapes are unchanged; api/openapi.yaml declares the header on each response. otelsetup builds the tracer provider with AlwaysSample, so an inbound traceparent with the sampled flag off still gets an exported span under the caller's trace ID; rememberSpan checks IsSampled anyway, so the header can never name an unexported trace (design decision, 2026-10-17).
  • Handler flow:
    1. Parse the VIN with model.ParseVIN (a domain rule: trim, upper-case, check), then bind the query string with Gin (ShouldBindQuery into dto.ListQuery: limit defaults to 20 and must be 1 to 100; an empty limit= counts as absent, so it takes the default). Both happen before the service is called.
    2. One call: agg.List(ctx, aggregator.ListRequest{Query, Cursor, Limit}). The service decides first page or resume, decodes and encodes the cursor, and returns its own errors (ErrInvalidCursor, ErrCursorOutdated, ErrSourcesUnavailable), which go to writeError.
    3. Otherwise write 200 through dto; next_cursor is the result's NextCursor, or null when it's empty.
  • Graceful shutdown: the Gin engine is the http.Server handler; Shutdown on SIGTERM with a 10s grace period.

// writeError turns err into a JSON error response. A 4xx message is the
// mapping's fixed text, or the error's own when it describes the request (an
// invalid VIN names the rule it broke); binding and cursor errors always get
// fixed text. 5xx messages are fixed, so internals never leak.
func (h *Handler) writeError(c *gin.Context, err error) {
	if errors.Is(err, context.Canceled) {
		c.AbortWithStatus(StatusClientClosedRequest) // no one to answer; the 499 is for logs and metrics only
		return
	}
	var su *aggregator.SourcesUnavailableError
	if errors.As(err, &su) {
		msg := "no source can answer; retrying won't help"
		if su.Retryable() {
			msg = "no source answered; retry with the same cursor"
		}
		c.AbortWithStatusJSON(http.StatusBadGateway, dto.ErrorResponse{
			Error:   dto.ErrorDetail{Code: dto.CodeSourcesUnavailable, Message: msg},
			Sources: dto.Statuses(su.Sources),
		})
		return
	}
	for _, m := range errorMap {
		if errors.Is(err, m.target) {
			c.AbortWithStatusJSON(m.status, dto.ErrorResponse{Error: dto.ErrorDetail{Code: m.code, Message: cmp.Or(m.message, err.Error())}})
			return
		}
	}
	h.log.ErrorContext(c.Request.Context(), "unhandled error", "err", err)
	c.AbortWithStatusJSON(http.StatusInternalServerError,
		dto.ErrorResponse{Error: dto.ErrorDetail{Code: dto.CodeInternal, Message: "internal error"}})
}
  • Errors flow up, mapping happens once. Handlers return as soon as something fails and call writeError; no handler picks a status code itself. Even the 502 comes from the aggregator's ErrSourcesUnavailable.
  • Sentinels by layer: model.ErrInvalidVIN (domain); dto.ErrInvalidLimit (request); aggregator.ErrSourcesUnavailable, ErrInvalidCursor and ErrCursorOutdated (service); source.ErrPermanent (port); client.Err* (clients). The handler only ever sees the first three groups.
  • Adding an error means adding one row to errorMap and one to the table above; nothing else changes.
  • The invalid-cursor message is fixed, because the cursor's wording could reflect its contents, and the cursor carries the VIN.

8. Redaction (logs and traces)

pkg/redact is generic and isolated: it redacts key/value fields and free text by whatever rules it is given, and imports no logging or tracing library. Using it on logs or traces is the caller's choice, through opt-in adapter packages: redactslog (an slog.Handler) and redactotel (a span exporter). The PII policy is configuration, kept in internal/telemetry/pii.go.

  • Setup: otelsetup.Setup(ctx, Options{ServiceName, Version, WrapLog, Exporters}) builds the trace, metric and log providers and the root slog handler; WrapLog is the hook redaction plugs into. Exporters is nil in production, meaning all three signals go to OTLP (endpoint from the standard OTEL_* variables); tests pass in-memory exporters, and a nil field inside a provided set discards that signal. Export failures are logged at debug through the service's own logger, not OpenTelemetry's stderr handler. Shutdown flushes all three on exit.
  • How it plugs in: redactslog.Handler implements slog.Handler and wraps the next handler, the way HTTP middleware wraps an http.Handler. Handle rewrites each record before passing it on; WithAttrs redacts logger.With(...) attributes once, up front; Enabled and WithGroup defer to the next handler.
  • Where (this service's choice): redactslog.NewHandler wraps the root slog.Handler once, before records fan out to stdout and the OpenTelemetry bridge, so both sinks get the redacted record. redactotel.NewExporter wraps the span exporter, so every attribute is redacted on export, including ones added after a span started.
  • Switch: telemetry.redact.enabled (default true), read at start. When it's off, the wiring skips both wraps entirely, so there's no cost and no half-redacted state, and the service logs a warning at start so it can't go unnoticed. The switch lives in the wiring, so pkg/redact stays generic.
package redact // rule-driven redaction of fields and free text; imports no logging or tracing library

type Action int

const (
	Keep Action = iota
	Drop // remove the field
	Mask // replace the value with asterisks, leaving its last KeepLast characters
)

type Rule struct {
	Action   Action
	KeepLast int // for Mask: trailing characters left visible; 0 masks everything
}

type Config struct {
	Rules           map[string]Rule  // by field key
	Patterns        []*regexp.Regexp // matches in free text and string values are masked
	PatternKeepLast int              // trailing characters left visible in each match
}

// Redactor applies a Config. It is safe for concurrent use.
type Redactor struct{ cfg Config }

func New(cfg Config) *Redactor { return &Redactor{cfg: cfg} }

// Rule returns the rule for key, or Keep.
func (r *Redactor) Rule(key string) Rule { return r.cfg.Rules[key] }

// Field redacts one value: it returns the new value, and keep=false when the
// field must be dropped. Kept values are still scrubbed of pattern matches.
// Keys never change, so callers never track renamed fields.
func (r *Redactor) Field(key, value string) (string, bool) {
	switch rule := r.Rule(key); rule.Action {
	case Drop:
		return "", false
	case Mask:
		return mask(value, rule.KeepLast), true
	}
	return r.Text(value), true
}

// Text masks every pattern match in free text, such as a log message.
func (r *Redactor) Text(s string) string {
	for _, p := range r.cfg.Patterns {
		s = p.ReplaceAllStringFunc(s, func(m string) string { return mask(m, r.cfg.PatternKeepLast) })
	}
	return s
}

// mask replaces all but the last keep runes with '*'. A value no longer than
// keep is masked entirely, so a short value is never shown in full.
func mask(s string, keep int) string {
	rs := []rune(s)
	if keep >= len(rs) {
		keep = 0
	}
	n := len(rs) - keep
	return strings.Repeat("*", n) + string(rs[n:])
}
package redactslog // opt-in: a redact.Redactor as an slog.Handler

// Handler redacts every record, and attributes added with With, before
// passing them on.
type Handler struct {
	next slog.Handler
	red  *redact.Redactor
}

func NewHandler(next slog.Handler, red *redact.Redactor) *Handler {
	return &Handler{next: next, red: red}
}

// Enabled defers to next: redaction never changes what gets logged.
func (h *Handler) Enabled(ctx context.Context, l slog.Level) bool { return h.next.Enabled(ctx, l) }

// WithGroup passes the group on; attributes inside it are still redacted by
// their own key.
func (h *Handler) WithGroup(name string) slog.Handler {
	return &Handler{next: h.next.WithGroup(name), red: h.red}
}

func (h *Handler) Handle(ctx context.Context, r slog.Record) error {
	out := slog.NewRecord(r.Time, r.Level, h.red.Text(r.Message), r.PC)
	r.Attrs(func(a slog.Attr) bool {
		if a, keep := h.attr(a); keep {
			out.AddAttrs(a)
		}
		return true
	})
	return h.next.Handle(ctx, out)
}

// WithAttrs must redact too: attributes added with logger.With(...) never
// pass through Handle's record.
func (h *Handler) WithAttrs(as []slog.Attr) slog.Handler {
	var kept []slog.Attr
	for _, a := range as {
		if a, keep := h.attr(a); keep {
			kept = append(kept, a)
		}
	}
	return &Handler{next: h.next.WithAttrs(kept), red: h.red}
}

// attr returns the redacted attribute, or keep=false to drop it.
func (h *Handler) attr(a slog.Attr) (slog.Attr, bool) {
	a.Value = a.Value.Resolve() // a LogValuer becomes its value first
	if a.Value.Kind() == slog.KindGroup {
		var kept []slog.Attr
		for _, g := range a.Value.Group() {
			if g, keep := h.attr(g); keep {
				kept = append(kept, g)
			}
		}
		return slog.Attr{Key: a.Key, Value: slog.GroupValue(kept...)}, true
	}
	if !textual(a.Value) && h.red.Rule(a.Key).Action == redact.Keep {
		return a, true // a number, bool, duration or time can't carry text
	}
	value, keep := h.red.Field(a.Key, a.Value.String())
	if !keep {
		return slog.Attr{}, false
	}
	return slog.String(a.Key, value), true
}

// textual reports whether v can carry free text: strings, and anything that
// isn't a plain scalar (errors, Stringers, structs), which is rendered as text
// and scrubbed. An error's text often holds a full upstream URL, VIN included.
func textual(v slog.Value) bool {
	switch v.Kind() {
	case slog.KindInt64, slog.KindUint64, slog.KindFloat64, slog.KindBool, slog.KindDuration, slog.KindTime:
		return false
	}
	return true
}

Design notes

  • WithAttrs, groups and error values are the easy places to leak. Attributes attached with logger.With("vin", v) go through WithAttrs, not Handle; nested groups need recursion; and an error's text often carries a full upstream URL, VIN included (*url.Error), so non-scalar values are rendered and scrubbed. All three are covered by tests.
  • Messages are constant; data goes in attributes. Rules work by key, so they can't see inside a message; only patterns can, and only for shapes they know (a VIN, not a customer's name). sloglint's static-message check enforces constant messages in CI.
  • Mask, not hash. A keyed hash would let one VIN be followed across requests, but needs a secret key to create, rotate and share. Masking needs no key; within a request the trace ID ties the log lines together, and the last 4 characters usually tell vehicles apart.
  • The core never imports a logging or tracing library. Code that only needs to redact a map, an audit record or an error message uses redact alone; the adapters are separate packages it opts into.
  • One wrap, at the root. Redacting before the fan-out means a new sink can't skip the rules.
  • The policy is data. Changing what counts as PII means editing pii.go, not the redaction code.

10. Mock systems (test harness)

Not part of the architecture: the mocks only have to return realistic data when called, following the contracts in HLD section 5.

  • mock-sales on :8081 and mock-service on :8082. Each loads its fixture file into memory on start, sorted per VIN newest first, and serves keyset pages in its own schema (HLD section 5), using its own response structs rather than the clients' wire models.
  • Keyset paging in memory:
package mock

// Key is a record's place in newest-first order.
type Key struct {
	At time.Time
	ID string
}

// Store holds one mock system's records per VIN, sorted newest first:
// date descending, then ID descending, with IDs compared by cmpID
// (as strings for Sales, as numbers for Service). It is generic over the
// record type, so each mock keeps its own response struct.
type Store[T any] struct {
	byVIN map[string][]T
	key   func(T) Key
	cmpID func(a, b string) int
}

// Page returns up to limit records for vin that come after `after`
// (nil: from the newest), and whether more remain.
func (s *Store[T]) Page(vin string, after *Key, limit int) ([]T, bool) {
	recs := s.byVIN[vin]
	start := 0
	if after != nil {
		start = sort.Search(len(recs), func(i int) bool { return s.older(s.key(recs[i]), *after) })
	}
	end := min(start+limit, len(recs))
	return recs[start:end], end < len(recs)
}

// older reports whether k comes strictly after a in newest-first order.
func (s *Store[T]) older(k, a Key) bool {
	if !k.At.Equal(a.At) {
		return k.At.Before(a.At)
	}
	return s.cmpID(k.ID, a.ID) < 0
}

Most Service records carry work_notes; only a few Sales documents carry notes. A few files appear in both systems with matching checksums (fixed values in the fixtures).

  • Fault controls: POST /admin/faults with a body such as {"latency_ms": 2500, "error_rate": 0.5, "hang": false}, or {"status": 403} to make every call fail permanently; DELETE /admin/faults resets. Environment variables set the startup defaults. This lets the demo push one system into failure live, without a restart.

11. Bootstrap and wiring

Each entry point wires only what it needs. The HTTP API's dependencies live with it, in internal/handler/api/dependencies.go; a future gRPC server or queue consumer would get its own dependencies.go next to its handler. Constructors live in their own packages (salesapi.New, sales.Build, aggregator.NewBuilder), so two entry points needing the same pieces call the same constructors instead of copying code.

Adding a source touches no existing logic: write its client and adapter packages (the adapter exports Name and Build), add one line to sourceBuilders, and one entry under sources.upstreams in the YAML. The wiring loop gives its client the tracing and resilience stack, and the builder checks it. A source configured without an adapter fails startup; an adapter not configured is simply not wired.

Bootstrap (cmd/docviewer/main.go), in order:

  1. Load .env if present (configload.LoadDotEnv(".env")), then config: configload.Load[config.Config](configload.Options{Path: configload.ResolvePath("configs"), EnvPrefix: "DOCVIEWER", Strict: true}). Strict, so a misspelt key fails instead of being silently ignored. Invalid config exits 1 before anything starts; the loader's errors never echo secrets.
  2. Set up telemetry (pkg/otelsetup, with the redaction hook), so everything after it logs and traces.
  3. api.NewDependencies(cfg, tel) builds the HTTP API's graph.
  4. api.NewServer(cfg.Server, deps) builds the Gin router, middleware and routes inside an http.Server.
  5. Serve until SIGINT or SIGTERM (signal.NotifyContext), then shut down in reverse.
package api

// Lister is what the handlers need from the aggregator: one page per call.
// Declared here, on the consumer's side, so handler and error-mapping tests
// run against a fake; *aggregator.Aggregator satisfies it.
type Lister interface {
	List(ctx context.Context, req aggregator.ListRequest) (aggregator.Result, error)
}

// Dependencies is everything the HTTP handlers use, and nothing else.
// Telemetry carries the instruments and providers NewServer installs (otelgin
// and the metrics-recording request logger); tests build real telemetry over
// in-memory exporters through the same constructor, so production code has
// no nil checks.
type Dependencies struct {
	Aggregator Lister
	Telemetry  *telemetry.Telemetry
	Log        *slog.Logger
}

// sourceBuilder builds one source (its client and adapter) from its config.
type sourceBuilder func(baseURL string, hc httpjson.Client) (source.Source, error)

// sourceBuilders is the one list a new source is added to. Each adapter
// package provides its Name and Build; nothing else in the wiring changes.
var sourceBuilders = map[model.Source]sourceBuilder{
	sales.Name:   sales.Build,
	service.Name: service.Build,
}

// NewDependencies builds the HTTP API's graph from configuration: one HTTP
// stack, client and adapter per configured source, then the aggregator.
func NewDependencies(cfg config.Config, tel *telemetry.Telemetry) (*Dependencies, error) {
	b := aggregator.NewBuilder(aggregator.Config{RequestTimeout: cfg.Sources.RequestTimeout}, tel.Logger()).Observe(tel.Metrics())
	for name, up := range cfg.Sources.Upstreams {
		build, ok := sourceBuilders[model.Source(name)]
		if !ok {
			return nil, fmt.Errorf("source %q is configured but has no adapter", name)
		}
		hc := httpjson.Client{HTTP: upstreamHTTP(name, cfg.Resilience, tel), MaxBytes: cfg.Sources.MaxBodyBytes}
		src, err := build(up.BaseURL, hc)
		if err != nil {
			return nil, fmt.Errorf("source %q: %w", name, err)
		}
		b.AddSource(src, up.Timeout)
	}
	agg, err := b.Build()
	if err != nil {
		return nil, err
	}
	return &Dependencies{Aggregator: agg, Log: tel.Logger()}, nil
}

// upstreamHTTP is one upstream's client stack: tracing, then resilience with
// that upstream's own breaker, then a pooled transport.
func upstreamHTTP(name string, r config.Resilience, tel *telemetry.Telemetry) *http.Client {
	base := http.DefaultTransport.(*http.Transport).Clone()
	guarded := resiliencehttp.NewTransport(base, name, upstreamPolicy(r, tel), failedResponse) // policy from section 5
	return &http.Client{Transport: otelhttp.NewTransport(guarded)}
}

Shutdown, the reverse of start:

  1. Readiness turns false, so a load balancer stops sending traffic.
  2. http.Server.Shutdown drains in-flight requests, for up to server.shutdown_grace.
  3. Telemetry flushes spans, metrics and logs.
  4. Exit 0, or 1 if any step failed.

12. Test plan

Strategy: table-driven tests throughout. Each test is a table of cases (name, input, expected result) run as subtests with t.Run, so adding a case means adding a row, and a failure names the case. Three layers work together:

  • Acceptance tests from the PRD: each acceptance criterion (AC-01 to AC-12) is a row in an end-to-end table, named after its ID, so every requirement has a test that says which one it proves.
  • Unit tests per package, with fakes for their dependencies.
  • End-to-end tests: the service built as in production, against both mocks in process.

Coverage target: at least 80% of statements in internal/ and pkg/, checked by make cover, which fails below it. cmd/ (wiring only, exercised by the end-to-end tests) and generated code (stringer) are excluded. Coverage is a floor, not the goal: the acceptance rows say what is actually proven.

Rule: no test logic in production code. No test-only flags, branches, hooks or exported helpers in non-test files. Tests reach what they need through the seams production already has:

  • interfaces the code uses anyway (fake source.Sources for the aggregator), constructors, and httptest servers for clients;
  • _test.go files in the same package for unexported code, with export_test.go when an external test needs an internal;
  • testing/synctest for time, so production code needs no clock abstraction just to be tested;
  • the mocks, a separate test harness the service never imports.

13. Implementation order

The order to write the code in, not compile order (Go works that out from the imports). It runs bottom-up along the dependency graph in section 2, so each step builds only on packages that already exist and pass their tests, and each step is a small, reviewable unit of work for the coding agent.

  1. pkg/configload and the service schema, then the model package and VIN tests.
  2. pkg/httpjson, the shared client sentinels, then both clients with their tests.
  3. Mock servers with in-memory fixtures and keyset paging, plus their tests and the contract fixtures.
  4. The source port, errmap, and both adapters with mapping tests.
  5. The aggregator (State, paging, partial failure, parallelism, coalescing) with fake sources, then cursor.go.
  6. HTTP layer with dto, dependencies.go and server.go, the main.go bootstrap, the OpenAPI spec and end-to-end tests.
  7. pkg/resilience (Guard), then resiliencehttp (NewTransport), wired into each client's http.Client.
  8. pkg/otelsetup, pkg/redact with its two adapters, the PII policy, the service's metrics, docker-compose with the Grafana stack, and the dashboard.
  9. README and cURL examples.
